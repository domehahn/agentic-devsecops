# Large Language Models: Deep Foundations, Scaling Laws, Alignment, and Systemic Boundaries

A Large Language Model is often described by what it can do: answer questions, write code, summarize documents, translate languages, plan tasks, or call tools.

A more durable definition begins with what it computes.

For a token sequence \(x_1,\dots,x_T\), a causal language model factorizes:

\[
p(x_1,\dots,x_T)=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t})
\]

That equation is the foundation beneath much of modern generative AI.

## Tokens Are the Computational Alphabet

LLMs do not directly consume words. Text is converted into tokens that may correspond to words, fragments, punctuation, bytes, or code pieces.

Tokenization affects both efficiency and representation. Rare languages and unusual technical identifiers may require more tokens than common patterns.

Language is an application of sequence modeling, not a primitive built into the mathematics.

## The Transformer Solved a Training Bottleneck

Before Transformers, recurrent neural networks processed sequences through recurrent hidden state:

\[
h_t=f(h_{t-1},x_t)
\]

The Transformer replaces recurrence in its central representation mechanism with attention.[^1]

\[
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
\]

\[
A=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)
\]

The causal mask \(M\) prevents access to future positions.

This makes training much more parallelizable across token positions than classical recurrence. It does not make autoregressive generation fully parallel.

## Decoder-Only Architecture and the Modern LLM

Many general-purpose LLMs use decoder-only Transformers.

A simplified block:

```text
input hidden state
   ↓
normalization
   ↓
causal self-attention
   ↓
residual
   ↓
normalization
   ↓
MLP
   ↓
residual
```

Repeated many times:

```text
tokens
 ↓
embeddings
 ↓
Transformer block × N
 ↓
final normalization
 ↓
vocabulary projection
 ↓
logits
```

Modern systems may also use mixture-of-experts, grouped-query attention, rotary positional embeddings and other optimizations.

## Self-Attention Is Contextual Routing, Not Explicit Meaning

Attention computes content-dependent weighted interactions between positions.

It can transport information about entity references, variable definitions, constraints, or local syntax.

But semantics arise from the full network, not attention weights alone.

## Pretraining: Learn the Distribution Before Learning the Assistant

Pretraining is generally self-supervised: text supplies the targets.

Pretraining can learn syntax, facts represented in the corpus, code, styles and reasoning patterns.

But a raw pretrained model is optimized to continue text, not necessarily to follow instructions, refuse unsafe requests, ask clarifying questions or use tools correctly.

That is the purpose of post-training.

## Instruction Tuning Changes Conditional Behavior

Supervised instruction tuning trains on prompt-response pairs.

It changes how the model maps user intent and context to responses. It should not be confused with a targeted factual update mechanism.

If information changes frequently, retrieval or tools are usually more appropriate.

## RLHF and Preference Optimization

In RLHF, humans compare outputs, a reward signal is learned or constructed, and the policy is optimized toward preferred behavior. InstructGPT demonstrated the effectiveness of this approach.[^2]

Direct Preference Optimization later provided a simpler preference-learning formulation.[^3]

Post-training can improve helpfulness, style, safety and tool use, but it does not provide a general truth oracle.

## Scaling Laws: Empirical Regularities, Not Physical Laws

Kaplan et al. found approximate power-law relationships between loss and model size, data and compute over studied regimes.[^4]

Chinchilla later showed that compute-optimal training required more data for many model sizes than previous scaling choices implied.[^5]

Scaling therefore involves balancing:

```text
parameters
training tokens
compute
data quality
architecture
```

Power laws imply diminishing returns as well as improvement.

## Data Quality Becomes More Important as Scale Increases

Large corpora contain duplicates, benchmark contamination, stale facts, toxic content and private information.

Deduplication research has shown that duplication can increase memorization and distort evaluation.[^6]

The training corpus is therefore part of the architecture.

## “Emergence” Requires Careful Language

Some tasks show apparently abrupt capability changes with scale. Wei et al. highlighted emergent abilities.[^7] Later work argued that some discontinuities depend strongly on metric choice and can appear smoother under alternative measures.[^8]

The engineering takeaway is to test capabilities directly rather than infer them from model size.

## Inference Is a Runtime Pipeline

A production call involves:

```text
request
 ↓
tokenization
 ↓
context construction
 ↓
prefill
 ↓
KV cache
 ↓
autoregressive decode
 ↓
sampling
 ↓
validation / post-processing
```

Prefill and decode have different performance characteristics.

Sampling settings such as temperature and top-p materially change output behavior.

## Context Windows Are a Systems Boundary

Large context windows do not mean every token is equally useful.

Long contexts create higher prefill cost, attention dilution, retrieval noise, conflicting instructions, stale history and prompt-injection exposure.

Context engineering means selecting the right information, with provenance and authority, rather than inserting everything.

## LLMs Are Not Databases

Parameter memory is probabilistic and context-dependent.

For volatile or high-stakes facts:

```text
LLM parametric knowledge
    ↓ insufficient alone
external source
    ↓
retrieval / tool
    ↓
evidence
    ↓
generation
```

RAG was introduced to combine parametric and non-parametric memory.[^9]

RAG improves grounding but does not guarantee truth.

## Hallucination Is an End-to-End Property

A model can hallucinate because information was absent, retrieval failed, context conflicted, decoding selected an incorrect continuation, or evaluation failed.

Useful controls include retrieval, citation, abstention, structured tools, deterministic validation and external verification.

## From LLM to Agent

An LLM becomes part of an agent when software adds goal, state, tools, a control loop, memory, evaluation and authorization.

A model-generated sentence may be wrong. A model-generated shell command may change a system.

Therefore:

```text
model proposal
≠
authorization
```

## Governance and Security

LLM governance spans the model, data, application and operational layers.

NIST AI RMF provides a lifecycle structure through Govern, Map, Measure and Manage.[^10]

## Conclusion

A Large Language Model is best understood as a **large-scale probabilistic inference engine over token sequences**.

Its capabilities emerge from Transformer architecture, massive data, self-supervised prediction, scale, post-training and runtime context.

The most important production insight is:

> The LLM is a powerful inference component, not the entire intelligent system.
