# Large-Scale Autoregressive Neural Networks: A Formal View of Sequential Generative Inference

Autoregression is older than modern artificial intelligence.

What changed with deep learning was not the core probability factorization but the **capacity of the conditional model**.

A modern Transformer can use enormous parameter counts and large contexts to estimate each conditional distribution, turning a classical sequential assumption into a general-purpose generative computation paradigm.

## The Chain Rule Is the Starting Point

For a sequence \(x_{1:T}\):

\[
p(x_{1:T})=\prod_{t=1}^{T}p(x_t\mid x_{<t})
\]

An autoregressive model parameterizes:

\[
p_\theta(x_t\mid x_{<t})
\]

For language, \(x_t\) is a token. For other modalities it may represent image tokens, audio codes, actions or symbolic events.

Autoregression is about ordered factorization, not specifically about text.

## “Higher-Order Markov Model” Is Only an Analogy

A fixed-order Markov assumption says:

\[
p(x_t\mid x_{<t})=p(x_t\mid x_{t-k:t-1})
\]

A Transformer with a context window can condition on all visible prior positions within that window.

Its limitation is not a fixed Markov order but finite context and imperfect use of context.

## Historical Continuity

Autoregressive modeling appears in time-series models, n-gram language models, neural language models, RNNs and Transformers.

Bengio et al. introduced distributed word representations into neural probabilistic language modeling.[^1]

The progression can be summarized as:

```text
explicit short history
→ learned compressed history
→ attention over large visible history
```

## Decoder-Only Transformers Implement Causal Conditioning

Attention scores:

\[
S=\frac{QK^\top}{\sqrt{d_k}}
\]

are modified by a causal mask:

\[
S_{ij}=-\infty \quad \text{for } j>i
\]

before softmax.

This enforces that position \(i\) may use positions up to \(i\), but not future tokens.

## Training Parallelism Versus Generation Sequentiality

During teacher-forced training, many token losses can be computed in one forward pass because the true prefix is known.

During generation:

```text
context
 ↓
generate x1
 ↓
append
 ↓
generate x2
 ↓
append
 ...
```

Each step depends on the generated prefix.

KV caching reduces redundant computation but does not remove token-by-token dependency.

## The KV Cache as Runtime Memory

For each Transformer layer, prior tokens produce keys and values.

With caching:

```text
prefill:
compute K,V for prompt

decode:
compute K,V only for new token
reuse cached history
```

This improves decode efficiency but memory grows with sequence length, layers, attention dimensions and concurrent sequences.

## Sampling Changes Effective Behavior

The model produces logits \(z_i\).

Temperature modifies softmax:

\[
p_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}
\]

Other methods include top-k, top-p, repetition penalties and constrained decoding.

Thus:

```text
model behavior
=
weights
+
context
+
decoding configuration
```

## Autoregressive Drift

A generated token becomes part of the next input:

```text
prediction_t
   ↓
context_(t+1)
   ↓
prediction_(t+1)
```

An early error may shift the later distribution.

Models can self-correct, but the system has no independent return to ground truth unless external evidence is introduced.

## Exposure Bias and Teacher Forcing

During training, the model conditions on true prefixes. During generation, it conditions on its own sampled outputs.

This mismatch is often called exposure bias.

Its practical significance depends on task and model, but it helps explain why long free-running generation can differ from token-level validation behavior.

## Scale Expands the Conditional Function

Increasing parameters does not change the chain-rule factorization.

It makes \(p_\theta(x_t\mid x_{<t})\) more expressive.

Scaling-law studies show regular improvements across substantial ranges.[^2]

But capacity, data, compute and architecture interact.

## Are Autoregressive Models Knowledge Systems?

They can behave as if they contain extensive knowledge, but their internal representation differs from explicit knowledge bases.

A knowledge base may contain:

```text
(Paris, capital_of, France)
```

An autoregressive model contains parameters whose computation makes particular continuations probable under particular contexts.

This matters for updates, provenance, consistency, deletion and auditability.

## Hallucination as Distribution Completion

When evidence is weak, the probability distribution still exists.

Hallucination can therefore arise because sequence completion under uncertainty is not truth verification.

Grounding changes the evidence available to the model but does not make the generator logically infallible.

## Emergent Abilities and Measurement

Some benchmarks show apparently sudden capability jumps with scale. Others become smoother under different metrics.[^3][^4]

The production lesson is direct:

> Do not infer a capability from scale. Test it.

## Alternative Generative Paradigms

Autoregression is not exclusive.

Other paradigms include masked modeling, diffusion, non-autoregressive generation, retrieval and symbolic systems.

Production architectures often combine them.

## Why Autoregression Became Dominant

Several properties align well with scaling:

1. simple likelihood objective;
2. abundant training data;
3. teacher forcing allows parallel training;
4. variable-length sequence modeling;
5. open-ended generation.

The costs are sequential decoding and probabilistic correctness.

## Systemic Boundaries

A production autoregressive model needs context selection, tokenization, serving, sampling, retrieval, tools, validation, monitoring and policy.

The model should not be confused with the whole system.

If it generates a dangerous command, whether that command is executed is a runtime authority decision.

## Conclusion

Large-scale autoregressive neural networks are best understood as **high-capacity sequential conditional models**.

Their fundamental equation is simple:

\[
p(x)=\prod_t p(x_t\mid x_{<t})
\]

Their power comes from the richness of each conditional model.

Their limitations are equally structural: sequential decoding, context dependence, self-generated history and probabilistic rather than truth-preserving output.
